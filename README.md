# MeshPilot

**Джарвис и инструменты обслуживания CachyOS на вашем столе.**

Десктопное приложение (Linux, x86_64): локальная «приборная панель» системы, чат-ассистент
с инструментами, безопасная очистка кэшей, управление зеркалами pacman, DNS и обходом
блокировок — без телеметрии и без скрытых действий.

> Статус: **developer preview (этап 2)**. Фронтенд проверен (`tsc`, `vitest`, `vite build`).
> Rust/Tauri-бэкенд написан и покрыт юнит-тестами парсеров/инвариантов, но на этой машине
> не собирался (нет тулчейна). Гейт сборки — CI (см. ниже). Не использовать для критичных систем без проверки на вашем железе.

## Что внутри

| Раздел | Что делает |
|---|---|
| Обзор | CPU (всего и по ядрам), RAM/swap, диски с дедупликацией по устройствам, сеть (RX/TX), датчик температуры (hwmon, если есть), аптайм |
| Джарвис | Чат с Groq/OpenRouter (OpenAI-совместимый API). Инструменты только для чтения и навигации: телеметрия, анализ очистки, статус DNS/зеркал, открыть раздел. Ничего не меняет в системе без вас |
| Очистка | 9 категорий воспроизводимых кэшей (pacman, миниатюры, браузеры, мессенджеры, dev-кэши, корзина, shader-кэш Steam/Mesa, journald/coredumps, yay/paru). С явными риск-бейджами, подтверждением и оптин-галочками для рискованных категорий |
| Сеть | Зеркала pacman (rate-mirrors / reflector / cachyos-rate-mirrors) с бэкапом; DNS: бенчмарк реальных резолверов сырым UDP, применение только в systemd-resolved или статический /etc/resolv.conf; обход через byedpi (только loopback, стратегии проверяются по факту); расписания через systemd user timers (только отчёты) |
| Разрешения | Честная диагностика: что работает без root, что требует sudo -n, чего нет на этой машине |
| Настройки | Провайдеры и модели, API-ключи (системное кольцо Secret Service; при его отсутствии — только память процесса), резервный провайдер, сброс настроек без потери ключей |

## Быстрый старт (CachyOS / Arch)

```bash
sudo pacman -S --needed rust nodejs-lts-22 npm webkit2gtk-4.1 libayatana-appindicator librsvg cmake gcc make
git clone <репозиторий> && cd MeshPilot/apps/desktop
npm ci
npm run tauri dev     # окно приложения
```

Проверки:

```bash
npm run check         # tsc
npm test              # vitest
npm run build         # production-сборка фронтенда
cd src-tauri && cargo test && cargo clippy --all-targets -- -D warnings
```

Демо-режим: вне Tauri (обычный браузер, `npm run dev`) интерфейс показывает **помеченные**
демо-данные: бейдж «ДЕМО» в боковой панели, баннер в чате, ничего не удаляется и не отправляется.

## Ключи и приватность

- API-ключи хранятся только в **системном кольце** (Secret Service / gnome-keyring / KWallet).
  Если кольцо недоступно — ключ живёт только в памяти процесса и исчезает при выходе (об этом прямо сказано в интерфейсе).
- Ключи **никогда** не попадают в файл настроек, экспорт настроек, историю чата, логи и сообщения об ошибках.
- Нет телеметрии, нет аналитики, нет фоновых сетевых запросов. Сеть используется только по вашему действию
  (тест подключения, бенчмарк DNS, тест стратегий, сообщение Джарвису).

## Структура

```
apps/desktop/            фронтенд (React 18 + Vite + TypeScript, без UI-фреймворков)
  src/pages/             экраны: Обзор, Джарвис, Очистка, Сеть, Разрешения, Настройки
  src/lib/api.ts         типизированный IPC-слой + помеченный демо-провайдер вне Tauri
  src-tauri/             Rust-бэкенд (команды Tauri 2, без плагинов fs/shell)
  src-tauri/src/         snapshot, cleanup, network (mirrors/DNS/bypass), llm, settings, secrets, schedules, perms
docs/                    ARCHITECTURE.md, SECURITY.md, PROJECT_STATE.md
tests/native-window.sh   проверка нативного окна под xvfb (в CI)
.github/workflows/ci.yml фронтенд + Rust fmt/clippy/test + сборка + окно под xvfb
```
