# MeshPilot · решения

| Дата UTC | Решение | Причина и следствие |
|---|---|---|
| 2026-11-20 | Использовать закреплённую `arena/9c5d61a6-meshpilot` для PR в `main` | Название ветки сессии неизменно. В `main` не пушим; для слияния и релиза нужно отдельное разрешение. |
| 2026-11-20 | Три crates в workspace; Tauri v2 — отдельный application manifest с lockfile | Системные библиотеки WebKitGTK не мешают сборке CLI по SSH. Не создаём пустых заглушек служб. Бинарник GUI `meshpilot-desktop`, команда CLI и будущий PKGBUILD `meshpilot`. |
| 2026-11-20 | Только пассивные локальные чтения; `null` отделён от отрицательного ответа | Нельзя показать «онлайн», нулевые обновления или готовность снапшота без источника. `doctor` отличает недоступность, отсутствие и другую ОС. |
| 2026-11-20 | Отделить чистый план от исполнения | Идентичный PlanId и тело возвращают тот же JobId. Другое тело того же плана — ошибка. В JSON ID передаётся строкой. Сейчас модель в памяти, устойчивость к перезапуску не обещана. |
| 2026-11-20 | Не вводить Tokio и D-Bus без работающего агента | Tokio войдёт с первыми асинхронными проверками этапа 2. Сейчас GUI не имеет системных команд, только возможности управления своим окном. |
| 2026-11-20 | Предложено: сетевой откат вне GUI и agent | Таймер готов до первой записи, откат сравнивает владельца, сеть и ревизию каждого поля. Запрет прямого маршрута сильнее попытки восстановить интернет. |
| 2026-11-20 | Предложено: согласовывать точный набор пакетов и отмечать необратимую границу | После начала установки нельзя прерывать процесс кнопкой. После сбоя не переигрываем транзакцию автоматически, а сверяем журнал и реальное состояние. |
| 2026-11-20 | Окно по приёмочным ширинам: 4/2/1 при 1920/1280/768 px | Условие «при 1280 — две» уточняет противоречивый порог 1200. Сайдбар всегда 260 px; сетка и заглушки проверяются по DOM собранного приложения. |
| 2026-11-20 | Отделить контрольную точку Arena от бэкапа продукта | В `/MeshPilot/STATE.md` допустим только несекретный текст проекта. Продукт запрашивает только App Folder; ключ в системном хранилище, не в JSON или Dropbox. Путь на карточке макета — подпись, а не разрешение на файловый доступ. |
| 2026-11-20 | Минимальный CI без секретов и публикации | `pull_request`, `contents: read`, SHA действий, закреплённые toolchain, Node и lockfiles. Нативный smoke-тест на одноразовом Linux runner. |
| 2026-11-20 | Не нормализовать буквальный `ID=arch` в Live ISO | Для `NAME=CachyOS` нужен также `DISTRIB_ID=CachyOS` в `/etc/cachyos-release`. Не делать вывод по ID_LIKE, названию ядра или одиночному файлу. `status` сохраняет исходный `os_id`. |
| 2026-11-20 | Испытывать готовые бинарники на подписанном Live ISO с двумя read-only CD | Гость загружает собственное ядро и графический сеанс; нет NIC, пишущего диска, SSH и общих папок. Явный отрицательный результат при недостающем runtime предпочтительнее установки пакетов в ходе теста. |
| 2026-11-20 | Сообщать о файлах WebKitGTK в `doctor` отдельно от готовности CLI | Гость 260809 подтвердил отсутствие двух soname. CLI работает без них; `doctor` не исполняет `ldd`, не предполагает пути Arch на чужой ОС, не устанавливает пакеты. Самостоятельная работа графической сессии также не засчитывается за окно MeshPilot. |
