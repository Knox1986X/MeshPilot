# MeshPilot — куча идей (roadmap)

## Голос и персонаж
1. **Клонирование голоса** (RVC/SoVITS/XTTS) — свой Jarvis/Khan/Anime без Piper
2. **Смена голоса на лету** голосом: «говори как Хан» — переключение профиля без перезапуска
3. **Эмоциональный TTS** — радость/грусть/шёпот через prosody-теги
4. **Шёпот-режим** — тихий TTS + субтитры, если поздно ночью
5. **Мультиязычность** — автоопределение RU/EN/JP по STT, ответ на том же языке
6. **Live2D модели** — несколько персонажей (Jarvis-бот, Хан-сталкер, Мико-аниме), смена по настроению
7. **VRM 3D** — полноценный 3D аватар с жестами (жест «стоп», кивок)
8. **Lip-sync visemes** — точные фонемы (A/I/U/O), а не только амплитуда
9. **Реакции персонажа** — моргает, зевает, засыпает при простое, радуется при успехе чистки
10. **Сидит на окнах** — dock к любому окну (X11/Wayland), прячется на fullscreen
11. **Click-through для игр** — персонаж не мешает кликам в играх
12. **Голосовые скиллы** — «поставь таймер», «открой YouTube», «запусти игру»
13. **Wake word обучение** — своя модель «MeshPilot» за 10 минут записи
14. **Голосовой ввод в любом поле** — нажми Ctrl+Alt+M и диктуй в любое приложение
15. **TTS в Discord/Telegram** — бот-мост: голос ассистента в войс-чат

## LLM и агент
16. **LangGraph backend** — опциональный графовый агент вместо ReAct (циклы, ветвления)
17. **AutoGen/CrewAI** — мультиагенты: один чистит, другой проверяет, третий отчитывается
18. **Планировщик** — «каждое воскресенье в 3 часа чисти систему и отчитывайся»
19. **Долговременная память** — факты о пользователе, привычки, предпочтения (SQLite уже есть)
20. **RAG по документации CachyOS/Arch** — ассистент отвечает по wiki, а не галлюцинирует
21. **Tool-маркетплейс** — плагины: Spotify, Home Assistant, умный дом, браузер-автоматизация
22. **Офлайн-режим** — Hermes локально + faster-whisper + Piper = полный офлайн без интернета
23. **Гибридный каскад** — Groq для простых вопросов, Hermes для приватных, GigaChat для RU-специфики
24. **Стриминг ответов** — TTS начинает говорить до конца генерации (sentence-by-sentence)
25. **Interrupt** — перебиваешь ассистента голосом, он замолкает и слушает

## Оптимизатор CachyOS
26. **Автозапуск при загрузке** — systemd user service, чистка по расписанию
27. **Профили оптимизации** — «Игровой», «Батарея», «Сервер», «Максимальная скорость»
28. **Бенчмарк до/после** — замер загрузки, RAM, FPS до и после чистки
29. **Удаление остатков приложений** — orphan-конфиги в ~/.config, ~/.local/share, /opt, /usr/share
30. **Чистка snap/flatpak/docker/podman** — неиспользуемые рантаймы, образы, volumes
31. **Оптимизация загрузки** — анализ systemd-analyze, отключение медленных сервисов
32. **Ядро и драйверы** — проверка linux-cachyos, mesa, nvidia, firmware обновлений
33. **Файловая система** — fstrim, btrfs snapshots cleanup, subvolume audit
34. **Сеть** — TCP tuning (BBR congestion), MTU, IPv6, firewall (ufw/nftables) аудит
35. **Энергосбережение** — TLP/auto-cpufreq интеграция, батарея health
36. **Игровые оптимизации** — gamemode, mangohud, proton-ge, latency (RT kernel)
37. **Браузерный тюнинг** — флаги Chromium/Firefox для скорости, блокировщики
38. **Логи и coredumps** — ротация, лимиты, анализ ошибок systemd
39. **Пакетный менеджер** — AUR helper (yay/paru) интеграция, paccache auto, downgrade
40. **Зеркала** — автообновление mirrorlist раз в неделю, geo-IP выбор
41. **DNS** — DoH/DoT, AdGuard Home локальный, split-DNS для VPN
42. **Zapret2** — hostlist только для заблокированных, автообновление стратегий, GUI переключатель
43. **VPN fallback** — если zapret не помогает, предложить WireGuard/Outline
44. **Health-score** — оценка системы 0-100 с рекомендациями, история в графике
45. **Отчёт голосом** — «Система здорова, освободил 2.3 ГБ, зеркала обновлены, DNS — Cloudflare»

## GUI и UX
46. **Тёмная/светлая тема**, кастомные темы под персонажа
47. **Виджеты на рабочий стол** — CPU/RAM/сеть/температура поверх обоев
48. **Уведомления** — «Чистка завершена», «Zapret2 обновлён», «Диск почти полон»
49. **Горячие клавиши** — Ctrl+Alt+M (голос), Ctrl+Alt+O (оптимизатор)
50. **Мобильный пульт** — управление MeshPilot с телефона (WebSocket/Telegram bot)
51. **Telegram-бот** — голосовые сообщения в Telegram → MeshPilot отвечает голосом
52. **Discord-бот** — ассистент в Discord войс-канале
53. **Web-интерфейс** — управление через браузер (FastAPI + HTMX), для headless серверов
54. **Мультимонитор** — персонаж на каждом экране или только на главном
55. **Режим стримера** — OBS source, overlay для стримов, TTS для чата

## Интеграции
56. **Spotify/YouTube Music** — «включи плейлист», «пауза»
57. **Home Assistant** — свет, розетки, датчики голосом
58. **Календарь/задачи** — напоминания, таймеры, будильники
59. **Файлы** — «найди документ», «открой загрузки», голосовой файловый менеджер
60. **Скриншоты/запись** — «сделай скриншот», «запиши экран 10 секунд»

## Безопасность и приватность
61. **Локальный режим по умолчанию** — ничего не уходит в облако без согласия
62. **Шифрование памяти** — SQLite с SQLCipher, ключи в keyring
63. **Аудит действий** — лог всех опасных операций (sudo, удаление), undo для чистки
64. **Подтверждение голосом** — «Удалить 12 пакетов? Скажи „да“»
65. **Песочница tools** — опасные tools только с явного разрешения

## Производительность
66. **GPU-ускорение** — faster-whisper на CUDA, Piper на GPU, Hermes на Vulkan
67. **Кэширование LLM** — одинаковые вопросы без повторного запроса
68. **Предзагрузка моделей** — STT/TTS в RAM, быстрый старт
69. **Лёгкий режим** — на слабых ПК: tiny STT, Piper, Hermes 3B
70. **Профилирование** — замер latency каждого этапа голосового цикла
