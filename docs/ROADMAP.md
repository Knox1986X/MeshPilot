# MeshPilot · дорожная карта

Срез: этап 1. ID неизменны. P0 — целостность, безопасность или блокирующий критерий; P1 — основной сценарий; P2 — расширение. Номер этапа в таблице — когда проверяется полный результат, а не дата обещанного выпуска. «План» — не реализовано, «Часть» — реализованный фрагмент указан явно. Колонка «Проверка» описывает критерий, **не** прогон. Выполненные команды — в [STATE](STATE.md).

| Этап | Условие выхода до следующего этапа |
|---|---|
| 1 · Каркас | CLI, тесты чистой логики, CI, окно без системных эффектов, неизвестные данные без нулей |
| 2 · Диагностика | На одноразовой CachyOS проверены источник, время, единицы измерений, offline; ни одной записи в рабочую базу или сеть |
| 3 · Пробная сеть | VM: падения GUI, agent и helper, смена Wi-Fi, split DNS и запрет прямого выхода не нарушают политику |
| 4 · Транзакции | VM: питание, место, блокировка, подпись, хук, ESP, частичный итог; журнал выдерживает перезапуск |
| 5 · Интерфейс | Пять рабочих экранов, доступность без трея, согласия, профили, история, системные адаптеры |
| 6 · Перенос | Ревизии, проверка AEAD, предпросмотр импорта, сборка PKGBUILD; релиз только с отдельного разрешения |
| 7 · Android | Общие фикстуры, согласия VpnService и установщика, восстановление после разрыва связи |
