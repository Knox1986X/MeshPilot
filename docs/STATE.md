**Реализовано:** `crates/meshpilot-linux/src/cpu.rs` дважды читает агрегат `/proc/stat` без root. CLI и нативная карточка используют один расчёт, показывают процент, фактический интервал и время UTC. `cpu: null` означает недостоверный замер, 0 % — подтверждённый простой. Один раз при открытии и по кнопке; без потока, истории или измерений по ядрам. Формат: `crates/meshpilot-core/src/report.rs`; мост и capability: `apps/desktop/src-tauri`; отображение: `SnapshotCard.svelte`, `measurements.ts`. [Контракт](ARCHITECTURE.md), [решения](DECISIONS.md), [100 требований](ROADMAP.md).
