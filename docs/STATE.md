- Закоммичено: каркас `81d6b9d`, контракты и проверка первого запуска `6fa6b5f`, идентификация Live и стенд `5ac336f`, непривилегированный KVM `73a5f2f`, диагностика файлов GUI `7244fb4`. Отдельный профиль Handheld проверен в `98e974b`, итоговый стенд — `3aef0e7`. Изменения этой приёмки относятся к `tests/cachyos-vm/`, workflow и документации; приложение не получало дополнительных прав.
- Workspace `meshpilot-{core,linux,cli}`, CLI только `status`/`doctor` с JSON, dry-run и кодами 0/2/3. `ID=arch` в Live подтверждается названием и отдельным маркером, исходный `os_id` сохраняется. В core — модели плана и недолговечный `JobBook`, нет зависимости от GUI/ОС. `apps/desktop` — Tauri v2/Svelte/TypeScript, отказ WebView при EUID 0, только собственные оконные capabilities. [Дерево проекта](../README.md).
- Локально выполнены `cargo fmt --all --check`, fmt для отдельного Tauri manifest, `cargo clippy --locked --workspace --all-targets -- -D warnings`, `cargo test --workspace --locked` (10 тестов), `cargo build --workspace --locked`, `git diff --check`. Debian 12: `status` → 0 (`debian`, `null`), `doctor` → 3. Локально KVM нет, гостевые результаты получены на одноразовом Actions runner.
- `python3 tests/project.py` — 3 теста, включая строки 01–100; `python3 tests/backup_schema.py` с `jsonschema==4.25.1` — 2 структурные проверки (не криптография). Проверены имя приложения и пространство имён по всем 65 отслеживаемым путям и содержимому текстовых файлов, включая workflow, а также внутренние ссылки документации. Локальные тесты окончательного стенда `python3 -m unittest discover -s tests/cachyos-vm` — 9 проверок, в том числе отказ от неверного хеша и отсутствие подписи; `bash -n` для shell-скриптов.
- [Обычный CI на `3aef0e7`](https://github.com/Knox1986X/MeshPilot/actions/runs/44818751695): workspace и desktop прошли, включая компиляцию Cargo-пакета ядра, npm, браузерный layout на 1920/1280/768 px и нативное окно на Ubuntu/Xvfb. Это не PKGBUILD или релиз. [Актуальные Checks PR](https://github.com/Knox1986X/MeshPilot/pull/1/checks).
- Файлы стенда: `fixtures.sh` — разрешённые пины; `media.sh` — ограниченная доставка; `verify.sh` — офлайн-проверка ISO/подписи; `run.sh`, `guest.py`, `verdict.py` — запуск, наблюдение и проверка протокола. Экспериментальная передача архива диапазонами удалена из текущего стенда. Для 251129 допустима только уже имеющаяся подписанная пара, без автозагрузки.
